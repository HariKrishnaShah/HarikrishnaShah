# Hi, I'm Hari 👋

I build software that local governments run on — spatial data, real-time dispatch, citizen services — at a scale where a bug means a real delay for a real person.

Currently completing my **M.Tech in Computer Science at NIT Rourkela**. Before that, I led full-stack development at **Diginirmaan** in Kathmandu, where I architected a GIS platform now used by 25+ municipalities across Nepal.

&nbsp;

## What I've built

**[Palika GIS](https://palikagis.com)** — the core platform. An emergency dispatch system pushing live GPS, severity, and media from residents to a management dashboard over Socket.io. An algorithmic house-numbering engine that assigns metric addresses based on proximity to roads. Full road-network mapping on PostGIS layers. A digital survey pipeline that's processed 100K+ responses with live batch logging and automated backups.

**[Tetra Labs](https://tetralabs.diginirmaan.com.np)** — a SaaS for civil testing labs. Automates the entire workflow from test request to lab data entry to report generation, with a role-gated portal for clients to download results.

**Linfra Go** — a GIS viewer for drone survey data: orthomosaics, 3D point clouds, contour maps, DEMs. Custom tiling pipeline (GDAL, MBTiles) to keep large spatial datasets responsive in the browser.

**[Municipal Platform](https://lalitpur.palikagis.com)** — a modular CMS for local governments, handling content, public events, and staff directories. Adopted by multiple municipalities beyond the original build.
